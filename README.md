# The Endless Library

A first-person cosmic horror game. You are a night auditor sent by Solen Group
to catalogue an old library before 06:00: finish the task list, follow the
protocol on your clipboard, and be back at the Circulation Desk when the shift
ends. The library is not what it seems.

This repository holds the game's builds only.

> **Early development.** Expect bugs, unfinished features and changes between
> versions.

## Download and play

1. Download the latest `EndlessLibrary-v….zip` from
   [Releases](https://github.com/leandro-santos-abreu/EndlessLibrary-releases/releases/latest).
2. Extract it. Keep the `EndlessLibrary` folder together: the game needs the
   `data_…` folder that sits beside the exe.
3. Run `EndlessLibrary.exe`.

**Requirements:** Windows 10 or 11 (64-bit) and a graphics card that supports
Direct3D 12.

The build is not code-signed, so Windows may say it protected your PC. Choose
**More info → Run anyway**.

## Updates

On the title screen the game asks GitHub for this repository's list of
releases. When a newer version is out, the menu shows **GAME VERSION** with
the new version number, which opens its download page. Nothing is downloaded or installed
automatically. To turn the check off, go to **SETTINGS → CHECK FOR UPDATES**.

## Reporting bugs

Open an [issue](https://github.com/leandro-santos-abreu/EndlessLibrary-releases/issues).
Say which version you played and what happened. Attaching the newest log from
`%APPDATA%\Godot\app_userdata\Endless Library\playtest_logs` helps a lot: it
records where you went and what happened during the shift.
